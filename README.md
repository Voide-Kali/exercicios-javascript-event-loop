# Exercícios JavaScript - Event Loop

Lista de exercícios sobre execução síncrona, macrotasks,
microtasks, setTimeout, Promise e async/await.

## Exercícios
1. Síncrono e setTimeout
2. Timers com tempos diferentes
3. Promise e Microtasks
4. Loop com let e setTimeout
5. Async e Await

## Executar
node exercicios/exercicio1.js
node exercicios/exercicio2.js
node exercicios/exercicio3.js
node exercicios/exercicio4.js
node exercicios/exercicio5.js
